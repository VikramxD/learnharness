## B. MCP client (Node)

**Version.** The target pins `@modelcontextprotocol/sdk` `1.32.1` (`package.json`, `package-lock.json:2437-2440`). Its `LATEST_PROTOCOL_VERSION` is `'2025-11-25'` (`dist/esm/types.js:2`), which matches alphaXiv.

**API.**
- Imports:
  - `Client` from `@modelcontextprotocol/sdk/client/index.js`
  - `StreamableHTTPClientTransport` and `StreamableHTTPError` from `@modelcontextprotocol/sdk/client/streamableHttp.js`
- Constructor: `new StreamableHTTPClientTransport(new URL(url), { requestInit: { headers: { Authorization: \`Bearer ${key}\` } }, fetch?, authProvider?, reconnectionOptions?, sessionId? })` (`client/streamableHttp.d.ts:58-100`).
- Methods: `client.connect(transport)`, `listTools()`, `callTool({ name, arguments }, undefined, { timeout, signal })` and `getServerCapabilities()` (`client/index.d.ts:159,431,539`).
- The default timeout is 60 s (`shared/protocol.js:8`).

**Reconnect.** The defaults are: initial delay 1000 ms, maximum delay 30000 ms, growth factor 1.5, `maxRetries: 2` (`streamableHttp.js:7-12`). These retries only re-open SSE streams: the GET stream, or a POST stream that has a resumption token (`:152-168, 238-256`). A failed POST is not retried and goes to the caller.

**Current use.** The target uses only the server side today. `src/agent/claude-code/tool-bridge.ts`:
- Builds a low-level `Server` with `StreamableHTTPServerTransport`.
- Listens on `127.0.0.1:<random>` behind a random Bearer token.
- Exposes pi-ai `Tool[]` to the `claude` CLI as `mcp__learnharness__<name>`.
- Queues each call for the harness to execute (`:19, 126-233`; from `stream.ts:722`).

The SDK client is used nowhere in `src/`.

**Both backends.** Tools are native pi `AgentTool`s on every backend. Plugins contribute them with `registerTools({ agents, create(context) })` for `prober`/`teacher`/`practice` (`src/core/plugins.ts:164-167`, `src/server/plugin-host.ts:259-266`, `docs/plugin-authoring.md:532-547`).
The claude-code backend reaches them through the bridge; pi backends call them directly. So an MCP client that wraps each remote tool as an `AgentTool` on that path reaches all backends with no core-loop edit. Constraint: names must be 1-64 characters of `[A-Za-z0-9_-]`, starting with a letter or underscore. Under claude-code each name gains the `mcp__learnharness__` prefix.

## C. alphaXiv auth and limits (https://alphaxiv.org/docs/mcp)

**Confirmed:**
- **API key:** created under "Settings > MCP/API" and sent as `Authorization: Bearer <key>`. It skips OAuth. Deleting the key revokes access immediately.
- **Server:** stateless, with "no `Mcp-Session-Id`". It runs revision 2025-11-25 and negotiates older revisions. Cross-origin browser calls are rejected, so call it from the backend only.
- **`read_files_from_github_repository`:** 150 calls an hour per account.
- **Size caps:** feed `limit` 1-200, GitHub files up to 250,000 bytes, PDFs 50MB.

**UNCONFIRMED (not stated on the page):**
- The key prefix.
- The assistant quota's size, reset and tiers.
- The HTTP status for rate-limit or quota errors (for example 429).
- Any global request rate limit.

## Risks for the plan

1. Copying `index.css` whole would clash with `globals.css` (`--background`, `--font-sans`, a different `dark` variant) and restyle upstream screens. Scope the tokens to the fork's shell, or merge them one at a time.
2. The big layout components depend on T3's client-runtime, effect atoms and the router. Plan to rebuild them, not copy them.
3. Base UI and Radix overlays nested inside each other may break focus or dismissal. Use one library per surface.
4. Version gaps: lucide 0.564 vs ^1.33 (icon names may differ) and React 19.3 vs ^19.2.8 (UNCONFIRMED impact). Typecheck catches most.
5. The trademark file names "visual trade dress", so a close visual copy carries some risk. Remove all T3 marks and state "unofficial" clearly.
6. The SDK does not retry a failed POST, and the shapes of 429 and quota errors are unknown. Tool wrappers must turn every error into a readable `isError` result.
7. Calling `listTools` remotely in a per-turn tool factory adds latency and a failure point to every turn. Cache the tool list at connect time.
8. The assistant quota is undocumented, so `discover_papers` loops can stop without warning.
